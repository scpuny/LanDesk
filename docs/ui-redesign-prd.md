# LanDesk 桌面客户端界面重构 PRD

> 版本：V1.0 ｜ 日期：2026-11-19 ｜ 状态：待评审
> 用途：驱动 Calicat 界面生成（高保真视觉稿）。本 PRD 只定义「用户看到的界面」，不涉及 Rust 内核与协议实现。
> 设计对标：向日葵远程控制、ToDesk —— 取其「设备列表 + 设备码连接 + 全屏会话窗口」的成熟范式，保留 LanDesk 自托管、安全可控的克制专业调性，不照搬消费级营销风格。

---

## 一、背景与目标

### 1.1 现状问题（基于现有代码事实）

当前 `ui/frontend` 是 Vue3 原生标签拼装的原型：无 UI 组件库、无状态管理、无路由、无图标、无主题、无设计系统（README 声称的 Arco Design 并未落地）。具体表现为：

1. 4 个视图（设备/会话/设置/日志）风格割裂：设备页白底裸列表、日志页黑底终端、状态栏半透明黑、设置页裸表单平铺；
2. 信息层次弱：无卡片分组、无设备状态可视化、无连接路径/链路表达；
3. 实时质量指标（延迟/丢包/码率/编码器/连接方式）仅以等权纯文本 `<span>` 呈现，无图形化表达；
4. 空状态、加载态、错误态简陋或缺失，异常被静默吞掉；
5. 会话画面区为纯黑空壳，缩放/全屏为无效占位交互；
6. 颜色、间距、字号硬编码且散落，中文文案被当作 CSS 类名使用（`.state.运行中`），不可维护。

### 1.2 重构目标

1. 建立一套完整、可复用的**设计系统**（色板、字体、间距、圆角、阴影、图标、组件、明暗主题）；
2. 交付**4 个核心页面**的高保真设计：设备（主页）、会话、设置、日志；
3. 参考向日葵/ToDesk 的成熟交互范式，做到「打开即懂、3 秒找到设备、1 次点击连接」；
4. 把会话质量与连接路径做成**可视化状态语言**，契合产品「稳定优先、可观测」的核心价值；
5. 所有视觉与交互状态（空/加载/错误/连接中/重连中/成功）均给出明确设计。

### 1.3 设计定位关键词

`专业可信` · `克制清爽` · `工具感` · `信息密度适中` · `状态一目了然` · `明暗双主题`

## 二、设计系统（Design System）

### 2.1 品牌与色彩

沿用现有品牌蓝 `#2F6FED` 并扩展为完整色阶。远程控制工具采用通用语义色，不使用金融涨跌配色。

| 类别 | 色值 | 用途 |
|---|---|---|
| Primary 主色 | `#2F6FED` | 主按钮、选中态、链接、焦点环 |
| Primary Hover | `#245BD4` | 主按钮悬停 |
| Primary Light | `#E8F0FE` | 选中背景、浅色标签底 |
| Brand Accent | `#00B4D8` | 在线/连接成功的点缀青色，用于状态呼吸点 |
| Success 成功 | `#16A34A` | 在线、连接成功、健康指标 |
| Warning 警告 | `#F59E0B` | 重连中、丢包偏高、降级 |
| Danger 危险 | `#DC2626` | 鉴权失败、无可用路径、断开 |
| Info 信息 | `#2F6FED` | 提示、说明 |

**中性色板（浅色主题）**：背景 `#F5F7FA`、表面 `#FFFFFF`、表面次级 `#F0F3F8`、边框 `#E3E8F0`、主文本 `#1D2433`、次文本 `#5B6577`、占位 `#9AA3B2`。

**中性色板（深色主题）**：背景 `#0E1420`、表面 `#171F2E`、表面次级 `#1F293B`、边框 `#2B3648`、主文本 `#E8EDF5`、次文本 `#9AA6BA`、占位 `#6B7688`。

> 会话预览画布区恒为纯黑 `#000000`，不受主题影响。

### 2.2 字体

- 字体族：`Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`
- 数字/设备码/指标：`"JetBrains Mono", "SFMono-Regular", Consolas, monospace`
- 字号阶梯：H1 24/32、H2 18/26、H3 16/24、正文 14/22、辅助 12/18、微标签 11/16
- 字重：标题 600、正文 400、强调 500；设备码 600 且字间距 `0.08em`

### 2.3 间距 / 圆角 / 阴影 / 描边

- 间距基准 4px，常用刻度：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40
- 圆角：小控件 6、卡片 10、弹窗 14、状态胶囊 999
- 阴影：卡片 `0 1px 3px rgba(16,24,40,.06)`；悬浮浮层 `0 8px 24px rgba(16,24,40,.12)`
- 描边：1px 实线；分隔线用中性边框色；焦点态用 Primary 2px 外发光 `0 0 0 3px rgba(47,111,237,.18)`

### 2.4 图标

- 统一线性图标库（推荐 Lucide / Tabler 风格），线宽 1.75px，尺寸 16 / 20 / 24 三档；
- 语义图标必须与文案成对出现，禁止纯图标表达关键操作；
- 设备类型图标：台式机、笔记本、开发板、显示器、服务器；连接路径图标：内网（局域网）、P2P（闪电直连）、中继（云）。

### 2.5 组件库清单（需全部产出）

`Button`（primary/secondary/ghost/danger，含 loading）、`Input`、`PasswordInput`（可切换可见）、`Select`、`Switch`、`Card`、`Tabs`、`Badge`、`StatusDot`（呼吸动画）、`Tag`、`Tooltip`、`Dropdown`、`Modal`、`Toast`、`EmptyState`（插画位）、`Skeleton`、`Avatar/DeviceIcon`、`SignalBars`、`MetricPill`、`Toolbar`、`ContextMenu`、`Divider`、`SearchBox`。

### 2.6 明暗主题

- 顶部导航右侧提供「太阳/月亮」主题切换，选择持久化；
- 所有色彩通过 CSS 变量（design token）驱动，禁止在组件内写死色值；
- 会话预览区、日志终端区在两种主题下均保持深色（工具属性）。

## 三、信息架构与全局框架

### 3.1 应用框架

- 最小窗口：`1180 × 760`；设计基准画布：`1440 × 900`；会话窗口可全屏。
- 布局：左侧固定导航栏 `width 208px` + 右侧内容区（自适应）。
- 顶栏 `height 56px`：左侧当前页标题 + 副标题，右侧「主题切换 / 通知 / 用户头像」。

左侧导航（自顶向下）：

| 分组 | 项 | 图标 |
|---|---|---|
| 主导航 | 我的设备（默认首页） | 显示器 |
| 主导航 | 远程会话 | 闪电 |
| 主导航 | 日志中心 | 文档 |
| 主导航 | 设置 | 齿轮 |

导航底部固定卡片：本机会话状态摘要（状态点 + `运行中/未连接` + 连接路径小字）。

### 3.2 页面清单

| 页面 | 路由 | 对应现有视图 | 优先级 |
|---|---|---|---|
| 设备（主页） | `/devices` | DeviceList.vue | P0 |
| 会话 | `/session` | Session.vue | P0 |
| 设置 | `/settings` | Settings.vue | P0 |
| 日志 | `/logs` | Logs.vue | P1 |

> 页面切换使用真实路由，保留滚动位置；会话进行中切换页面不中断连接。

## 四、页面详细设计

### 4.1 设备页（主页）— `/devices`

**目标**：这是打开软件的第一屏。用户在此「被别人连」（展示本机设备码）或「主动连别人」（设备列表一键连接 / 输入设备码连接）。

**布局**（内容区左右两栏，左主右次）：

```
┌──────────────────────────────────────────────────────────────────┐
│ 顶栏：我的设备    [我的在线设备 3]           [☀/🌙] [🔔] [头像]   │
├────────────┬─────────────────────────────────────────────────────┤
│            │  ┌─── 快速连接卡 ────────────────────────────────┐  │

│ 日志中心    │  └───────────────────────────────────────────────┘  │
│ 设置        │                                                    │
│            │  ┌─── 本机设备卡（被控信息）────────────────────┐   │
│            │  │ [设备图标] 我的设备  ·  在线●                  │   │
│            │  │ 设备码  8 3 F A  2 1 7 C      [复制]           │   │
│            │  │ 临时密码  6 2 9 4 1 8       [刷新] [复制]      │   │
│            │  └───────────────────────────────────────────────┘  │
│            │                                                    │
│            │  局域网设备  [🔄 刷新] [🔍 搜索设备]                │
│            │  ┌──────────┐ ┌──────────┐ ┌──────────┐            │
│            │  │◉ 开发主机 │ │◉ NAS-01   │ │○ OK3568板│            │
│            │  │192.168…12 │ │192.168…30 │ │离线 3分钟 │            │
│            │  │1920×1080  │ │1280×720   │ │—           │            │

│            │  └──────────┘ └──────────┘ └──────────┘            │
│ [状态摘要]  │                                                    │
└────────────┴─────────────────────────────────────────────────────┘
```

**区块详情**：

1. **快速连接卡（顶部通栏）**：设备码输入框（`Input`，等宽字体，占位 `请输入对方 8 位设备码`）+ Primary 按钮「远程控制」；下方「最近连接」历史胶囊，点击即填入并连接。
2. **本机设备卡（被控信息卡）**：设备图标 + 设备名（可点击改名）+ 在线状态点（绿色呼吸）；大号等宽「设备码」与「临时密码」两段，各带复制按钮；临时密码带「刷新」按钮（一次性密码场景）。此卡是向日葵/ToDesk 的标志性模块，视觉上要醒目（浅色 Primary Light 底纹 + 细边框）。
3. **局域网设备区**：标题 + 在线数量徽标 + 刷新按钮 + 搜索框；下方设备**卡片网格**（响应式 3→2→1 列，卡片最小宽 260px）。
   - 卡片内容：设备类型图标、设备名（截断省略）、在线/离线状态、`addr`（等宽小字）、分辨率、`enc` 编码能力 Tag、`relay=true` 时显示「中继可用」Tag。
   - 在线卡片 Primary「连接」按钮；离线卡片置灰「不可用」按钮 + `last_seen` 文案（如「离线 3 分钟」）。
   - hover：卡片上浮 2px + 阴影加深 + 边框转 Primary；点击卡片任意处等同「连接」。

**状态设计**：

- 加载：3 个设备卡片位 `Skeleton` 骨架屏；
- 空（未发现设备）：`EmptyState` 插画（雷达扫描图形）+ 标题「未发现局域网设备」+ 说明「请确认对方已开启 mDNS 广播，或切换到设备码连接」+ 次按钮「重新扫描」；
- 错误：`Toast` 顶部红色提示「发现服务不可用」，卡片区保留空状态；
- 搜索无结果：行内提示「没有匹配「xxx」的设备」。

### 4.2 会话页 — `/session`

**目标**：远程桌面主控窗口。参考 ToDesk/向日葵的全屏沉浸体验，画面最大化，工具栏悬浮不遮挡，状态信息压缩在底部条与顶部胶囊。

**布局**（会话未建立 → 建立中 → 运行中 三态共用同一框架）：

```
┌──────────────────────────────────────────────────────────────────┐
│ ●运行中  开发主机 · P2P直连                       [尺寸▾][全屏][⋯]│ ← 顶部悬浮胶囊工具栏
│                                                                  │
│                                                                  │
│                      远 端 画 面（黑色画布，自适应铺满）            │
│                                                                  │
│                                                                  │
│  ┌─ 左侧悬浮工具条 ─┐                                            │
│  │ 剪贴板 键鼠 截图 │                                            │
│  │ 显示器切换       │                                            │
│  └──────────────────┘                                            │
├──────────────────────────────────────────────────────────────────┤
│ 延迟 18ms ▮▮▮▮  丢包 0%  码率 4.2Mbps  编码 QSV  重置×0      [断开]│ ← 底部状态栏
└──────────────────────────────────────────────────────────────────┘
```

**区块详情**：

1. **画面区**：纯黑背景，远端视频铺满；「自适应」按窗口等比缩放并居中留黑边，「原始尺寸」1:1 显示并允许滚动。工具栏与状态栏在画面上悬浮显示，鼠标静止 3 秒后自动淡出、移动唤回。
2. **顶部胶囊工具栏**：状态胶囊（`StatusDot` + 状态文案 + 设备名 + 连接路径 Tag）；右侧「尺寸▾ 下拉（自适应/原始/1:1/50%/200%）」「全屏」「更多⋯（截图、剪贴板开关、显示显示器、日志）」。
3. **左侧悬浮工具条**：图标按钮组（剪贴板同步、键鼠模式、截图、显示器切换），带 `Tooltip` 说明。
4. **底部状态栏（数据可视化核心）**：将 `StatusBarModel` 的 7 个字段做成 `MetricPill`：
   - 状态：状态点颜色 + 文案（未连接/鉴权中/运行中/重连中/鉴权失败/无可用路径/已关闭）；
   - 连接方式：`内网 / P2P / 中继` 带对应图标与配色（内网蓝、P2P 青、中继橙）；
   - 编码器：芯片图标 + 名称（QSV/NVENC/AMF/V4L2M2M/VideoToolbox/OpenH264）；降级到 OpenH264 时标签转 Warning 橙；
   - 延迟：`18ms` + `SignalBars`（<30ms 4 格绿 / 30–80ms 3 格黄 / >80ms 2 格红）；
   - 丢包：`0%`，>3% 转橙、>10% 转红；
   - 码率：`4.2Mbps`；
   - 重置次数：`重置×0`，>0 时带 Tooltip 说明「编码器已自动重建」。

**状态设计**：

- 未连接：画面区 `EmptyState`（显示器插画）+「尚未连接远程设备」+ 主按钮「去选择设备」（跳转设备页）；
- 建立中：画面区居中 Loading（环形进度）+ 分阶段文案「正在协商密钥 → 正在探测路径 → 正在建立加密通道」+「取消」按钮；
- 重连中：画面保留最后一帧并覆半透明遮罩 + 「重连中（2/5）…正在尝试 P2P 直连」+ 进度条 +「断开」按钮；
- 鉴权失败 / 无可用路径：居中 Danger 图标 + 明确原因文案（密码错误 / 设备不存在 / nonce 异常 / 打洞失败且无中继）+ 主按钮「重新输入密码」、次按钮「返回设备列表」；
- 编码器降级：底部状态栏 Tag 转橙 + 非阻塞 `Toast`「硬件编码不可用，已切换 OpenH264 软编，会话保持」。

### 4.3 设置页 — `/settings`

**目标**：受控端配置面板（FR-08）。采用**横向表单布局**：label 左对齐、固定宽度 `140px`，字段按两列网格排布，长文本字段跨双列；按功能分组为卡片，避免裸表单平铺。

**布局**（内容区单列，纵向分组卡片，每卡内两列网格）：

```
┌───────────────────────────────────────────────────────────────┐
│ 基础信息                                              [卡片]   │
│  设备名        [____________________]   访问密码  [__________]👁│
│  编码预设      [平衡 ▾]                脏矩形检测  [开关]      │
├───────────────────────────────────────────────────────────────┤
│ 连接方式                                              [卡片]   │
│  mDNS 局域网广播  [开关] 说明：同一局域网内自动发现本机        │
│  外网信令注册    [开关] 信令地址 [ws://host:8443/ws________]   │
│  中继兜底        [开关] 说明：P2P 打洞失败时经中继转发          │
│  STUN 地址       [udp://host:3478________]                     │
├───────────────────────────────────────────────────────────────┤
│ 日志与诊断                                            [卡片]   │
│  日志级别       [Info ▾]  编码器日志 [查看]  配置文件路径 [打开]│
│  编码参数说明（长文本，跨双列）：预设对应码率 流畅1.5M/平衡4M/高清8M@1080p…│
└───────────────────────────────────────────────────────────────┘
                                              [重置] [保存配置]
```

**字段清单与控件**（对齐现有 `Config` 模型）：

| 分组 | 字段 | 控件 | 说明 |
|---|---|---|---|
| 基础信息 | `device_name` | Input | ≤32 字符 |
| 基础信息 | `password` | PasswordInput | 留空=不设置密码；提示「仅保存派生值，不存明文」 |
| 基础信息 | `preset` | Select | 流畅(1.5M)/平衡(4M)/高清(8M) |
| 基础信息 | `dirty_rect` | Switch | 脏矩形检测，提示「静止画面几乎不产生数据」 |
| 连接方式 | `mdns_enabled` | Switch | 局域网自动发现 |
| 连接方式 | `signaling_enabled` | Switch | 开启后「信令地址」输入变为必填 |
| 连接方式 | `signaling_url` | Input | 占位 `ws://host:8443/ws` |
| 连接方式 | `relay_enabled` | Switch | 中继兜底 |
| 连接方式 | `stun_url` | Input | 占位 `udp://host:3478` |
| 日志诊断 | `log_level` | Select | Info/Debug/Warn/Error |
| 日志诊断 | 编码器日志 | 链接按钮 | 跳转日志页并筛选 encoder |

**交互**：底部固定操作栏「重置」「保存配置」；保存时按钮 loading，成功后 `Toast` 绿色「配置已保存」；表单有未保存改动时顶部显示「有未保存的更改」提示；`signaling_enabled` 开启但地址为空时输入标红并显示校验文案。

**状态**：加载用 `Skeleton`；非 Tauri/REST 环境读取失败时展示行内错误条「配置读取失败，显示默认值」+「重试」，而非静默空白。

### 4.4 日志页 — `/logs`

**目标**：排障工具（FR-08.4 / NFR-06）。终端风格深色面板，支持过滤与级别高亮。

**布局**：


## 五、关键交互流程

1. **内网一键连接**：设备页 → 在线设备卡片点「连接」→ 切到会话页显示「建立中」→（内网直连）→ 运行中，状态栏显示「内网 · 18ms · QSV」。
2. **外网设备码连接**：快速连接卡输入 8 位设备码 →「远程控制」→ 弹出密码输入 `Modal`（含「一次性密码」选项）→ 校验 → ICE 打洞 → 成功走 P2P / 失败自动切中继（状态栏路径 Tag 实时变化）→ 运行中。
3. **断线重连**：QUIC 断 → 会话页覆「重连中 x/5」遮罩，保留最后一帧 → 指数退避 1/2/4/8s → 成功回运行中并强制 IDR；5 次失败→「无可用路径」错误态。
4. **编码器降级**：硬编驱动失效 → 会话不中断 → 底部编码器 Tag 转橙 + Toast 提示「已切换 OpenH264」；重置次数 +1。
5. **显示器切换**：会话页「显示器切换」→ 下拉展示 `DisplayInfo` 列表（分辨率）→ 选择 → 画面重建、状态栏短暂显示「分辨率已变更」。

## 六、状态与反馈规范

**会话状态 → 视觉映射**（避免用中文文案当 CSS 类，改用枚举映射）：

| 状态枚举 | 状态点色 | 状态栏文案 | 画面区表现 |
|---|---|---|---|
| Idle | 灰 `#9AA3B2` | 未连接 | 空状态插画 |
| Auth | 蓝呼吸 | 鉴权中 | 建立中 Loading |
| Running | 绿呼吸 | 运行中 | 实时画面 |
| Reconnecting | 橙呼吸 | 重连中 x/5 | 半透明遮罩 + 进度 |
| AuthFailed | 红 | 鉴权失败 | 错误态 + 重输密码 |
| NoPath | 红 | 无可用路径 | 错误态 + 中继引导 |
| Closed | 灰 | 已关闭 | 空状态 |

**反馈原则**：所有异步操作必须有 loading 与结果反馈（成功绿 Toast / 失败红 Toast）；破坏性操作（断开、清空日志、重置配置）需二次确认；错误必须给出「原因 + 可执行下一步」，禁止静默失败。

## 七、响应式与可访问性

- 窗口 ≥1180px 三列设备卡；900–1180px 两列；<900px 单列并折叠左侧导航为图标栏；
- 键盘可达：所有可交互元素支持 Tab 聚焦 + Enter 触发，焦点环用 Primary 外发光；
- 文本对比度 ≥4.5:1；状态不仅依赖颜色，同时有图标与文案；
- 尊重系统「减少动态效果」偏好，关闭呼吸/悬浮动画。

## 八、验收标准（界面生成交付检查）

1. 产出完整设计系统页（色板、字体、间距、组件库、明暗主题预览）；
2. 产出 4 个页面高保真稿，每页覆盖默认态 + 至少空态/加载态/错误态中的相关状态；

4. 会话页含「顶部胶囊工具栏 + 黑底画面 + 悬浮工具条 + 底部可视化状态栏」，状态栏含全部 7 项指标；
5. 设置页为横向表单（label 左对齐固定宽、两列网格、长文本跨双列）且按 3 组卡片分区；

7. 整体风格对标向日葵/ToDesk：专业、克制、工具感，为用户提供「3 秒找设备、1 次点击连接」的清晰路径；
8. 所有文案为中文，术语与现有 PRD/代码模型一致（设备码、连接路径、编码器、脏矩形等）。
